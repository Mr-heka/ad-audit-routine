# Ad Audit Routine

Runs a monthly ad review from your exports: what passed, failed or is missing, with one named owner and a date on every fix, and a check next month that the spend moved.

**Who it is for:** Owners who pay for ads and have no way to check what they are told about them.

**What you need:** Claude Code or Codex and a CSV or JSON export from Google Ads or Meta Ads. It can use the free Claude Ads project if you have it installed.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
